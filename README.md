# Кедр

Утилита для macOS: SACD ISO (DSD) и файлы DSF → PCM FLAC.

Образ Super Audio CD хранит однобитный DSD, часто ещё и сжатый в DST. FLAC так не умеет: он хранит PCM. Кедр читает оглавление, снимает DST, переводит DSD в 24-битный PCM и пишет FLAC с тегами из диска.

## Что нужно

- macOS 11 или новее
- [Homebrew](https://brew.sh)
- Python 3.9+, ffmpeg и `sacd_extract`

`sacd_extract` — отдельная программа из [sacd-ripper](https://github.com/sacd-ripper/sacd-ripper) (GPL-2.0). Обычный ffmpeg образ SACD не открывает. Код Кедра — MIT, extractor при установке скачивается и собирается отдельно.

## Установка на Mac

Из папки с этим файлом:

```bash
./scripts/install-macos.sh
open ~/Applications/Kedr.app
```

Скрипт ставит `cmake`, `libxml2`, `ffmpeg` и Python, собирает `sacd_extract` и кладёт приложение `Кедр` в `~/Applications`. Окно — локальная страница на `http://127.0.0.1:47631`. В интернет альбом не уходит.

Повторный запуск скрипта обновляет приложение после изменений в этой папке.

## Как пользоваться

1. «Выбрать файл» или вставьте путь к `.iso` / `.dsf`.
2. «Прочитать» — появятся исполнитель, альбом и дорожки. Если на диске есть стерео и 5.1, выберите зону.
3. Укажите папку. Внутри неё появится каталог `Исполнитель — Альбом`.
4. «Преобразовать в FLAC».

По умолчанию: 176,4 кГц, 24 бит, срез шума 40 кГц, сжатие FLAC 8. Срез убирает ультразвуковой шум DSD, которому в FLAC делать нечего. 352,8 кГц — без дополнительного понижения частоты, файлы заметно больше.

Промежуточные DSF удаляются. Если остановить задачу, уже записанные FLAC остаются.

## Командная строка

```bash
python3 -m kedr serve --open
python3 -m kedr info "/path/Album.iso"
python3 -m kedr convert "/path/Album.iso" -o ~/Music --mode stereo --rate 176400
python3 -m kedr convert "/path/Album.iso" -o ~/Music --mode multi --tracks 1,2,4
python3 -m kedr tools
```

`--mode multi` — многоканальная зона, если она есть на диске.

Запуск без команды поднимает то же окно: `python3 -m kedr`.

## Проверка

```bash
python3 -m unittest discover -s tests
```

Тест перевода DSF → FLAC гоняет синтетический тон 440 Гц. Полный SACD ISO в репозиторий не входит: это чужие записи.

## Ограничения

- Результат — PCM, не «бит-в-бит» DSD. Иначе это был бы DSF, а не FLAC.
- Нужен целый образ SACD, не DVD-Audio и не обычный CD ISO.
- Многоканальный FLAC воспроизводят не все плееры.
